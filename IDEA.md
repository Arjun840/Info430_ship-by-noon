# My app

**Domain:** Skiing

**User story:** As a skiier, I need to track and rate what routes I've taken on the mountain, so that I'm able to explore the mountain with ease, trying out new routes.

**What the user types or picks:** For a given ski resort, a user can select the routes they've taken, and give it a rating out of 5 or leave a comment about it. It's similar to a workout tracker but for skiing.
